# Introducción a Python

Repositorio público de apuntes, ejercicios y materiales de apoyo para el curso de introducción a Python.

## Web del curso

Este repositorio está preparado para publicarse con MkDocs.

En local:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

## Uso por parte del alumnado

Clona el repositorio una vez:

```bash
git clone URL_DEL_REPOSITORIO
```

Y actualízalo cuando el profesor publique nuevo material:

```bash
git pull
```

No entregues ejercicios modificando este repositorio. Las entregas se harán en el repositorio privado personal indicado por el profesor.
