    Introducción a la programación en Python¶

    Bienvenido al repositorio de apuntes y ejercicios del curso de introducción a la programación en Python.

    Este material está organizado de forma progresiva. Cada unidad puede incluir:

    • teoría
    • ejemplos
    • ejercicios
    • soluciones, cuando el profesor decida publicarlas.

    Cómo usar estos apuntes

    Puedes consultar la web desde el navegador o clonar el repositorio con Git para trabajar con los archivos .py en VS Code.

    Objetivo del curso¶

    El objetivo de este curso es aprender los fundamentos de Python desde cero y utilizarlos para resolver pequeños problemas de programación.

    No se busca memorizar instrucciones, sino aprender a pensar de forma ordenada:

    1. Entender el problema.
    2. Dividirlo en pasos.
    3. Escribir una solución sencilla.
    4. Probarla.
    5. Mejorarla.

    Materiales¶

    El repositorio contiene apuntes y ejercicios. El profesor irá publicando el material de forma progresiva.

    Puede ocurrir que una unidad tenga ya publicada la teoría, pero todavía no los ejercicios o las soluciones.

    Si ya has clonado el repositorio, puedes ir actualizándolo con:

    git pull

    Unidades¶

    El módulo consta de 100h, de las cuales, 61 horas se imparten en el centro. Para facilitar la planificación semanal de 3 horas, las unidades se organizan en bloques múltiplos de 3 horas y se reserva 1 hora de ajuste.

    Unidad Contenido Horas
    UT1 Introducción, entorno y tipos de datos 12
    UT2 Objetos predefinidos y cadenas de texto 3
    UT3 Control de flujo y librerías útiles para sysadmin 18
    UT4 Fundamentos de POO 0 en centro
    UT5 Estructuras de datos 15
    UT6 Funciones, módulos y ficheros 12
    Ajuste cierre, evaluación, incidencias o repaso 1
    Total 61
