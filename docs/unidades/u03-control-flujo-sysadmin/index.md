# UT3 - Control de flujo y librerías útiles para sysadmin

## Presentación

Esta unidad tiene una duración prevista de **18 horas en centro**.

**Resultado de aprendizaje principal:** RA3

## Qué vas a aprender

Tomar decisiones con condicionales, repetir acciones con bucles y depurar programas.

Además, en esta unidad se introduce el uso de librerías estándar de Python útiles para administración de sistemas, como `sys`, `os`, `platform`, `datetime`, `pathlib` y `shutil`. No se pretende memorizar todas sus funciones, sino aprender a consultar documentación, elegir funciones útiles y aplicarlas en pequeños scripts.


## Cómo se trabajará

- Lectura previa de teoría breve.
- Cuestionario flipped en Aules.
- Resolución de dudas en clase.
- Ejercicios para practicar.
- Ejercicios entregables cuando corresponda.
