# Alineación curricular de la unidad

| Elemento | Descripción |
|---|---|
| Unidad | UT3 - Control de flujo y librerías útiles para sysadmin |
| Horas en centro | 18 |
| RA principal | RA3 |
| Criterios de evaluación relacionados | CE3.1, CE3.2, CE3.3, CE3.4, CE3.5, CE3.6, CE3.7 |
| Qué se va a aprender | Tomar decisiones con condicionales, repetir acciones con bucles, depurar programas y usar librerías estándar útiles para administración de sistemas. |
| Evidencias de aprendizaje | Cuestionarios flipped, ejercicios de condicionales y bucles, entregables aplicados a sysadmin y prueba práctica. |

## Traducido a lenguaje sencillo

Al terminar esta unidad deberías ser capaz de explicar qué has aprendido, resolver ejercicios parecidos a los trabajados en clase y justificar las decisiones básicas de tu código.
