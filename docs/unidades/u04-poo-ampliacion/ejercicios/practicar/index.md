# Ejercicios de ampliación de POO

Estos ejercicios son voluntarios y están pensados para alumnado que quiera ir más allá.

## Ejercicio 1 - Clase Usuario

Crea una clase `Usuario` con atributos `nombre`, `email` y `activo`.

Añade un método `mostrar()` que imprima los datos del usuario.

## Ejercicio 2 - Clase Equipo

Crea una clase `Equipo` con atributos `hostname`, `ip` y `sistema`.

Añade un método `es_linux()` que devuelva `True` si el sistema es `Linux`.

## Ejercicio 3 - Clase Servidor

Crea una clase `Servidor` que herede de `Equipo` y añada el atributo `servicio`.

Añade un método que muestre un resumen del servidor.
