# UT6 - Funciones, módulos, ficheros, pathlib y glob

## Presentación

Esta unidad tiene una duración prevista de **12 horas en centro**.

**Resultado de aprendizaje principal:** RA5

## Qué vas a aprender

Organizar código en funciones, reutilizar módulos y automatizar tareas con ficheros, rutas, pathlib y glob/rglob.

## Cómo se trabajará

- Lectura previa de teoría breve.
- Cuestionario flipped en Aules.
- Resolución de dudas en clase.
- Ejercicios para practicar.
- Ejercicios entregables cuando corresponda.
