# UT2 - Objetos predefinidos y cadenas de texto

## Presentación

Esta unidad tiene una duración prevista de **3 horas en centro**.

**Resultado de aprendizaje principal:** RA2

## Qué vas a aprender

Entender de forma intuitiva qué es un objeto, usar métodos de cadenas, consultar documentación y escribir programas simples con objetos predefinidos.

## Cómo se trabajará

- Lectura previa de teoría breve.
- Cuestionario flipped en Aules.
- Resolución de dudas en clase.
- Ejercicios para practicar.
- Ejercicios entregables cuando corresponda.
