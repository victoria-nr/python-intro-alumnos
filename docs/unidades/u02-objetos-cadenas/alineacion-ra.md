# Alineación curricular de la unidad

| Elemento | Descripción |
|---|---|
| Unidad | UT2 - Objetos predefinidos y cadenas de texto |
| Horas en centro | 3 |
| RA principal | RA2 |
| Criterios de evaluación relacionados | CE2.1, CE2.2, CE2.3, CE2.4, CE2.6, CE2.7, CE2.9 |
| Qué se va a aprender | Entender de forma intuitiva qué es un objeto, usar métodos de cadenas, consultar documentación y escribir programas simples con objetos predefinidos. |
| Evidencias de aprendizaje | Cuestionario flipped, ejercicios de cadenas y práctica entregable. |

## Traducido a lenguaje sencillo

Al terminar esta unidad deberías ser capaz de explicar qué has aprendido, resolver ejercicios parecidos a los trabajados en clase y justificar las decisiones básicas de tu código.
