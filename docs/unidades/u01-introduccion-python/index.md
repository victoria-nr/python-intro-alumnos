# UT1 - Introducción, entorno y tipos de datos

## Presentación

Esta unidad tiene una duración prevista de **12 horas en centro** y trabaja principalmente el **RA1**.

## Qué vas a aprender

- Qué significa programar y cómo se ejecuta Python de forma básica.
- Cómo preparar y utilizar el entorno de trabajo.
- Cómo crear variables y reconocer tipos de datos.
- Cómo trabajar con números, booleanos, operadores y conversiones.
- Cómo manejar cadenas, entrada con `input()` y salida con `print()`.

## Metodología flipped

Antes de algunas sesiones leerás uno de los apartados de teoría y realizarás un cuestionario breve en Aules. Después, en clase, resolveremos dudas y haremos ejercicios prácticos.
