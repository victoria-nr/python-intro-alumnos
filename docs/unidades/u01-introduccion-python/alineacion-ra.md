# Alineación curricular de la unidad

| Elemento | Descripción |
|---|---|
| Unidad | UT1 - Introducción, entorno y tipos de datos |
| Horas en centro | 12 |
| RA principal | RA1 |
| Criterios de evaluación relacionados | CE1.1, CE1.2, CE1.3, CE1.4, CE1.5, CE1.6, CE1.7, CE1.8, CE1.9 |
| Qué se va a aprender | Ejecutar programas Python, usar variables, tipos básicos, operadores, entrada/salida por consola y conversiones de tipo. |
| Evidencias de aprendizaje | Cuestionarios flipped, ejercicios de práctica, ejercicios entregables y prueba práctica. |

## Traducido a lenguaje sencillo

Al terminar esta unidad deberías ser capaz de explicar qué has aprendido, resolver ejercicios parecidos a los trabajados en clase y justificar las decisiones básicas de tu código.
