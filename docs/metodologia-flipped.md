# Metodología flipped classroom

Durante el curso trabajaremos con una metodología de aula invertida.

## Antes de clase

Antes de cada sesión debes:

1. Leer el apartado de teoría indicado.
2. Revisar los ejemplos.
3. Anotar dudas concretas.
4. Prepararte para el cuestionario inicial en Aules.

## Al comenzar la clase

Durante los primeros 10-15 minutos se realizará un cuestionario breve sobre la teoría preparada en casa.

Los cuestionarios no están pensados para memorizar definiciones largas, sino para comprobar que has leído, entendido las ideas principales y detectado dudas.

## Durante la clase

El tiempo de aula se dedicará principalmente a:

- resolver dudas;
- analizar errores frecuentes;
- practicar con ejercicios guiados;
- resolver ejercicios entregables;
- mejorar programas paso a paso;
- explicar soluciones alternativas.

## Cómo estudiar la teoría

No intentes memorizar todo. Para cada apartado debes poder responder a estas preguntas:

- ¿Para qué sirve esto?
- ¿Qué problema resuelve?
- ¿Cuál es el ejemplo mínimo?
- ¿Qué error frecuente debo evitar?
- ¿Podría modificar el ejemplo para otro caso parecido?
